## 三、需要新开发的功能

### 3.1 场次管理（优先级：P0 - 核心功能）

**业务需求**：通航产品（如直升机观光、飞行体验等）需要按场次售票，每个场次有固定时间、容量限制。

**需要开发的内容**：

| 内容 | 说明 |
|------|------|
| 场次实体 `FlightSession` | 日期、开始时间、结束时间、容量、已售数量、状态 |
| 场次与产品关联 | 一个产品可配置多个场次 |
| 场次管理 CRUD | 后台增删改查、批量设置场次 |
| 下单选择场次 | 用户下单时必须选择可用场次 |
| 场次库存管控 | 下单扣减场次容量、取消/退款释放 |
| 场次日历视图 | 管理端按日历展示场次排期 |

**预估涉及文件**：

```
新增：
  - FlightSession.java（实体）
  - FlightSessionDao.java
  - FlightSessionService.java / Impl
  - FlightSessionController.java（admin）
  - FlightSessionRequest.java / Response.java

修改：
  - StoreProduct.java — 增加是否需要选场次标记
  - OrderServiceImpl.java — 下单时校验场次
  - StoreOrderInfoOldVo.java — 关联场次信息
```

**预估工期：5-7 天**

### 3.6 多场地管理与基于位置的商品筛选（优先级：P0 - 核心功能）

**业务需求**：航利特通航有多个飞行场地，不同场地提供不同的飞行产品。用户打开小程序后，根据地理位置自动展示最近场地的产品，也可手动切换场地。

**当前基础**：CRMEB 已有 `SystemStore`（门店/提货点）实体，包含名称、地址、经纬度，已有 Haversine 距离计算 SQL。但**商品没有关联门店/场地**。

**需要开发的内容**：

| 内容 | 说明 |
|------|------|
| 商品-场地关联表 | 多对多关系，一个产品可在多个场地提供 |
| 后台商品编辑增加场地选择 | 创建/编辑商品时选择归属场地 |
| 前台按场地筛选商品 | 商品列表查询增加 storeId 筛选 |
| "最近场地+商品"接口 | 根据用户经纬度自动找最近场地，返回该场地商品 |
| 场地切换功能 | 小程序首页场地选择器，可手动切换 |
| 场次关联场地 | 场次表增加 store_id，不同场地有不同场次 |

**数据库设计**：

```sql
-- 商品-场地关联表（多对多）
CREATE TABLE `eb_store_product_store` (
    `id` INT NOT NULL AUTO_INCREMENT,
    `product_id` INT NOT NULL COMMENT '商品ID',
    `store_id` INT NOT NULL COMMENT '场地ID（关联 eb_system_store）',
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_product_store` (`product_id`, `store_id`),
    KEY `idx_store` (`store_id`)
) ENGINE=InnoDB COMMENT='商品-场地关联表';

-- 场次表增加场地关联
ALTER TABLE `eb_flight_session`
    ADD COLUMN `store_id` INT NOT NULL COMMENT '场地ID';
```

**新增接口**：

```
GET /api/front/store/nearest-products?latitude=xxx&longitude=xxx
返回：最近场地信息 + 该场地的商品列表

GET /api/front/products?storeId=xxx
返回：指定场地的商品列表
```

**预估涉及文件**：

```
新增：
  - StoreProductStore.java（关联实体）
  - StoreProductStoreDao.java
  - StoreProductStoreService.java / Impl

修改：
  - StoreProductRequest.java — 增加 storeIds 字段
  - StoreProductServiceImpl.java — 保存时同步关联
  - ProductServiceImpl.java（front）— 列表查询增加场地筛选
  - StoreController.java（front）— 新增 nearest-products 接口
  - SystemStoreMapper.xml — 复用已有距离 SQL
  - FlightSession.java — 增加 store_id
```

**预估工期：2-3 天**

### 6.3 折扣优惠券 — 扩展方案

```sql

ALTER TABLE `eb_store_coupon`
    ADD COLUMN `coupon_type` TINYINT NOT NULL DEFAULT 1 COMMENT '1-面值券 2-折扣券',
    ADD COLUMN `discount` INT DEFAULT NULL COMMENT '折扣（80表示8折，仅折扣券使用）';
```

订单金额计算调整（`OrderServiceImpl`）：

```java
// 原逻辑：couponPrice = coupon.getMoney()
// 新逻辑：
if (coupon.getCouponType() == 1) {
    // 面值券：直接减去面额
    couponPrice = coupon.getMoney();
} else if (coupon.getCouponType() == 2) {
    // 折扣券：按比例计算优惠金额
    BigDecimal discountRate = new BigDecimal(coupon.getDiscount())
        .divide(new BigDecimal(100));
    couponPrice = orderPrice.multiply(BigDecimal.ONE.subtract(discountRate))
        .setScale(2, RoundingMode.HALF_UP);
}
```
